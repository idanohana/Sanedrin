# סנדרין

פלטפורמה בעברית לזוגות שמתחתנים באולם סנדרין: תהליך היכרות, ניהול מוזמנים, RSVP ב-SMS4FREE ומפת הושבה 2D/3D.

## הרצה מקומית

1. צרו פרויקט ב-[Supabase](https://supabase.com) והריצו את `supabase/schema.sql` ב-SQL Editor.
2. העתיקו `.env.example` ל-`.env.local` ומלאו את המפתחות.
3. התקינו והריצו:

```bash
npm install
npm run dev
```

האפליקציה תיפתח ב-`http://localhost:3000`.
